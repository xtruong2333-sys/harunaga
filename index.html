Hướng Dẫn Quản Lý Kênh Đối Thủ

1. Thêm hoặc Bớt Kênh Đối Thủ

Bạn chỉ cần mở file channels.json trên GitHub và sửa danh sách: 

[
  {
    "name": "Tên Kênh Đối Thủ",
    "handle_or_url": "@handle_kenh",
    "min_views_per_hour": 5000
  }
]

2. Tùy Chỉnh Ngưỡng Cảnh Báo

Bạn có thể đặt min_views_per_hour khác nhau cho từng kênh: Kênh to đặt 50.000, kênh trung bình đặt 5.000, kênh nhỏ đặt 1.000 view/h.

3. Tần Suất Quét

GitHub Actions tự động chạy mỗi 1 tiếng. Bạn cũng có thể bấm Run workflow trên GitHub để hệ thống quét ngay lập tức.
